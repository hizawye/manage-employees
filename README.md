# Manage Employees · إدارة الموظفين

An offline Android workspace for employee records, shifts, attendance and wages. The app supports Arabic and English. Employee and payroll data stay on the device. The update check reads public GitHub release information.

## Install on Android

[Download the latest APK](https://github.com/hizawye/manage-employees/releases/latest/download/Manage-Employees.apk) for a new installation or an update from a publisher-signed release. Inside the app, open **Profile → App updates → Check for updates**. Android asks you to confirm installation.

**Already using the original development app?** On Android 9 or newer, install the [one-time migration APK](https://github.com/hizawye/manage-employees/releases/latest/download/Manage-Employees-Migrate-Android9Plus.apk) over the installed app to keep its records. Immediately install the standard APK of the same version to finish the migration. Future updates use that standard APK. If the original development app is on Android 7 or 8, keep it installed. Uninstalling erases its local records.

## التثبيت والتحديث

للتثبيت لأول مرة، نزّل [ملف APK الرسمي](https://github.com/hizawye/manage-employees/releases/latest/download/Manage-Employees.apk). للتحقق من إصدار أحدث، افتح **الملف الشخصي ← تحديثات التطبيق**. إذا كانت لديك نسخة التطوير القديمة على أندرويد 9 أو أحدث، ثبّت [ملف الترقية لمرة واحدة](https://github.com/hizawye/manage-employees/releases/latest/download/Manage-Employees-Migrate-Android9Plus.apk) فوق النسخة الحالية للاحتفاظ بسجلاتك، ثم ثبّت ملف APK الرسمي للإصدار نفسه فورًا لإتمام الترقية. إزالة التطبيق تحذف بياناته المحلية.
