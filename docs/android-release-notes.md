Install **Manage-Employees.apk** on Android 7.0 and newer. If you already use a publisher-signed release, Android upgrades it in place. Future updates are available in **Profile → App updates**.

**Upgrading the original development installation?** On Android 9.0 and newer, install **Manage-Employees-Migrate-Android9Plus.apk** once. This transfers the existing installation to the publisher's signing certificate and preserves its data. Use the standard APK for later updates. On Android 7 and 8, the original development installation cannot move to the publisher's certificate in place. Uninstalling erases local employee records.

بعد تثبيت إصدار الناشر، ستجد التحديثات في **الملف الشخصي ← تحديثات التطبيق**. إذا كنت تستخدم نسخة التطوير القديمة على أندرويد 9 أو أحدث، ثبّت **Manage-Employees-Migrate-Android9Plus.apk** مرة واحدة للاحتفاظ ببياناتك، ثم استخدم **Manage-Employees.apk** للتحديثات التالية. إزالة التطبيق تحذف البيانات المحلية.
