Install **Manage-Employees.apk** on Android 7.0 and newer. If you already use a publisher-signed release, Android upgrades it in place. Future updates are available in **Profile → App updates**.

**Upgrading the original development installation?** On Android 9.0 and newer, follow both steps:

1. Install **Manage-Employees-Migrate-Android9Plus.apk** to migrate the existing installation and preserve its data.
2. **Immediately install Manage-Employees.apk from this same release** and confirm the update, even though the version number is identical. This finishes switching to the private publisher certificate. Use the standard APK for every later update.
 On Android 7 and 8, the original development installation cannot move to the publisher's certificate in place. Uninstalling erases local employee records.

بعد تثبيت إصدار الناشر، ستجد التحديثات في **الملف الشخصي ← تحديثات التطبيق**. إذا كنت تستخدم نسخة التطوير القديمة على أندرويد 9 أو أحدث، ثبّت **Manage-Employees-Migrate-Android9Plus.apk** مرة واحدة للاحتفاظ ببياناتك، ثم ثبّت فورًا **Manage-Employees.apk** من الإصدار نفسه وأكّد التحديث حتى لو ظهر رقم الإصدار نفسه. بعد هاتين الخطوتين، استخدم **Manage-Employees.apk** لكل تحديث لاحق. إزالة التطبيق تحذف البيانات المحلية.
