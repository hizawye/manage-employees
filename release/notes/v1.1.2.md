### What's new

- Install updates from **Profile → App updates**. The Work tab includes weekly scheduling, clock-ins, leave requests and payroll reports.
- The Android migration now transfers both existing records and the app's signature permission. If you're upgrading the original development installation, follow both installation steps below.

### الجديد

- ثبّت التحديثات من **الملف الشخصي ← تحديثات التطبيق**. يضم تبويب العمل الجداول الأسبوعية، وتسجيل الدوام، وطلبات الإجازة وتقارير الرواتب.
- تنقل الترقية الآن السجلات الموجودة وإذن التوقيع الخاص بالتطبيق. إذا كنت تستخدم نسخة التطوير القديمة، فاتّبع خطوتَي التثبيت أدناه.
